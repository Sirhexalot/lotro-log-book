1. Charakter in LOTRO Companion importieren

      for A in "$HOME/Applications" "/Applications"; do S="$A/The Lord of the Rings Online.app/Contents/SharedSupport"; [ -d "$S" ] && break done for C in "$HOME/Applications/LotRO Companion" "/Applications/LotRO Companion" "$HOME/Applications/"*/"LotRO Companion"; do [ -d "$C/app" ] && break done cd "$C/app" && WINEPREFIX="$S/prefix" WINEMSYNC=1 WINEESYNC=1 WINEDEBUG=-all \ DYLD_FALLBACK_LIBRARY_PATH="$S/wine/lib" "$S/wine/bin/wine64" "../LotRO Companion.exe"

      2. Hier laden

      Ordner unter Windows: %USERPROFILE%\.lotrocompanion\data\characters
      Ordner auf dem Mac (versteckt; im Auswahldialog ⌘⇧G drücken und einfügen): ~/Applications/The Lord of the Rings Online.app/Contents/SharedSupport/prefix/drive_c/users/Wineskin/.lotrocompanion/data/characters

      Ordner „characters“ hierher ziehen
