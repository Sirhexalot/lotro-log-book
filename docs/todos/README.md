# Offene Vorhaben

Dieser Ordner ist der verbindliche Ablageort für offene, technisch
umsetzbare Vorhaben des Website-Repositories.

Aktuell offen sind:

- [`aufgabenstatus-manuell.md`](aufgabenstatus-manuell.md) – Aufgaben und Taten
  manuell abhaken; ein passender Companion-Import überschreibt die manuellen
  Angaben.
- [`entitaetenvertrag-abgleich.md`](entitaetenvertrag-abgleich.md) –
  Entitätenvertrag je Entität und UI-Auftritt gegen Code und Tests abgleichen.
- [`gebietsansicht-gemeinsam.md`](gebietsansicht-gemeinsam.md) – gemeinsame
  Gebietsansicht für Karte und Übersichten.
- [`gegenstandsseite-quellgruppen.md`](gegenstandsseite-quellgruppen.md) –
  Quellgruppen auf Gegenstandsseiten ordnen.
- [`gegenstandsseiten-woher-wofuer.md`](gegenstandsseiten-woher-wofuer.md) –
  Gegenstandsseiten um Quellen und Verwendungen erweitern.
- [`klassen-voelker-filter.md`](klassen-voelker-filter.md) – Klassen-/Völkerprofile
  um belegte Aufgaben-, Taten- und Ausrüstungsfilter ergänzen.
- [`release-komponenten.md`](release-komponenten.md) – Releases und Uploads nach
  Komponenten trennen.

Ein Plan unter `~/.opencode/plan/` ist nur ein Arbeitsentwurf. Sobald ein
Vorhaben als Projekt-TODO gilt, liegt die maßgebliche Fassung hier. Erledigte
TODOs werden nach `docs/archiv/` verschoben, nicht gelöscht.
